Before this paper, there was a map. Navigator is a developer-portfolio template built around a cartographic theme: compass roses, bearing badges, a terrain grid drawn from GitHub contributions, and a terminal that answers to `whoami` and `neofetch`.

Everything is configured from a single file. Travel waypoints draw a route on a Leaflet map. Dev.to articles are pulled in at build time. Dark mode loads without a flash. The whole thing is published as an open template so that anyone can set sail with it.

The edition you are reading is its successor. The compass has been retired, with thanks.
